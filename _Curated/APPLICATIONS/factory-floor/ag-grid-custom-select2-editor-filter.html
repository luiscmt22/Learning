AG Grid Custom Editors and Filters with Select2 - Method-by-Method Walkthrough

A line-by-line dissection of a custom AG Grid cell editor backed by Select2 plus a custom Portuguese-localized text filter, including the focus and event-stopping bugs that were found.

Why does focus keep jumping to the wrong dropdown when you have three Select2 editors open in a grid? Because somewhere, someone wrote $('.select2-search__field').focus() and that selector finds every Select2 search field on the page. This document is what happens when you finally sit down and read your own code.

Executive summary

This document walks through three pieces of AG Grid integration code: an initializeSelect2() utility, a CustomSelectEditor that wraps Select2 inside an AG Grid popup editor, and a CustomTextFilter that fully replaces AG Grid's default text filter with Portuguese labels and dictionary-aware filtering. It explains every method, every config option, and flags four real bugs in the editor (e.g. the global $('.select2-search__field') selector that hijacks focus across all instances). It is essentially a code-archaeology pass on the FactoryFloor grid layer.

💡
MetaphorThink of AG Grid's editor and filter slots like USB ports on a motherboard: AG Grid promises to deliver power and data to whatever you plug in, as long as your component implements the contract (init, getGui, getValue...). Select2 isn't a USB device though, it's an old serial peripheral, so this code is the adapter cable wrapping a vintage jQuery plugin in a USB shell, complete with the loose wires that make focus jump to the wrong window when the dog walks past.

1Why it exists

FactoryFloor's grids needed dropdown editors that look up names from in-memory dictionaries (motoristas, viaturas, servicos) instead of showing raw IDs, plus a filter that searches against those human-readable names while keeping Portuguese terminology. The default AG Grid editor and filter couldn't do that, so Select2 was bolted on and a custom filter was written.

2What it does

initializeSelect2() converts every <select class='select2'> on the page into a Select2 dropdown with Portuguese localization. CustomSelectEditor builds a wrapper div, populates a <select> from params.values mapped through a context dictionary, then calls Select2 inside a setTimeout. CustomTextFilter constructs an AG-Grid-styled filter UI with a six-option dropdown (contains/equals/startsWith/etc.), a magnifying-glass input, and a 'Limpar Filtro' button; doesFilterPass converts array columns (servicosIds, viaturasIds) into searchable strings via dictionary lookup before applying the chosen comparison.

3How it works

The editor stores parameters, creates DOM elements imperatively, and chooses idToNameMap based on params.column.colDef.field. Select2 is initialized with dropdownParent: document.body (flagged as a problem because it breaks focus management). The filter implements AG Grid's lifecycle: init, getGui, isFilterActive, doesFilterPass, getModel/setModel for state restoration, and event handlers that call params.filterChangedCallback() to retrigger the grid. doesFilterPass case-insensitively compares with the cell value, joining array columns via dictionary[id]?.Nome before running the switch on filterType.

       } else if (columnField === 'viaturasIds') {



              dictionary = this.params.context.viaturasDict;

single values)



       let cellValueStr;

       if (Array.isArray(cellValue)) {



             // Handle array columns (servicosIds, viaturasIds)

              const readableValues = cellValue.map(id => {



                     const dictValue = dictionary[id];

                    return dictValue?.Nome || dictValue || id; //

Handle both object and string values

              });

              cellValueStr = readableValues.join(' ').toLowerCase();

       } else {

             // Handle single value columns (motoristaId, data,

              cellValueStr = cellValue.toString().toLowerCase();

       const filterTextLower = filterText.toLowerCase();

      // Apply filter based on filter type

       switch (this.filterType) {



              case 'equals':

                     return cellValueStr === filterTextLower;



              case 'notEqual':

                     return cellValueStr !== filterTextLower;



              case 'contains':

                     return cellValueStr.indexOf(filterTextLower) >= 0;



              case 'notContains':

                     return cellValueStr.indexOf(filterTextLower) === -



1;

              case 'startsWith':

                     return cellValueStr.indexOf(filterTextLower) ===



0;

              case 'endsWith':

                     return cellValueStr.indexOf(filterTextLower,



cellValueStr.length - filterTextLower.length) !== -1;

              default:

                     return false;



       }

};

Key takeaways

  • AG Grid editors must implement init, getGui, getValue, isPopup, destroy and optionally onKeyDown/afterGuiAttached
  • Filters need init, getGui, isFilterActive, doesFilterPass, getModel, setModel and a filterChangedCallback to refresh the grid
  • Global jQuery selectors like $('.select2-search__field') will steal focus across multiple component instances
  • Array columns can be made searchable by joining dictionary lookups into a single string before doesFilterPass runs the comparison
  • dropdownParent: document.body breaks AG Grid's focus management because the dropdown escapes the editor container
