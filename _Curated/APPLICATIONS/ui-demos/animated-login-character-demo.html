Animated Character Login Page (Interactive Demo)
A self-contained HTML demo of a login form where three SVG bird/duck characters track the cursor, cover their eyes when the password field focuses, and celebrate or frown based on authentication outcome — driven entirely by a CSS state-machine class on the root element.
Every login form has the same three fields and the same two buttons. What if the form watched you type and reacted like a nervous pet? This demo is 600 lines of HTML that makes a dead-serious auth screen actually fun to look at.
Executive summary
This is an interactive design prototype, not a written tutorial. A purple bird, a black bird, and a yellow duck sit beside a login form and react to user input via a state machine: their pupils track the mouse in s-idle/s-email states, they smile when the email validates, frown when it doesn't, raise both arms to cover their eyes in the s-password state, drop one arm for the s-peek state (show-password toggle), bounce in s-success, and shake in s-error. The entire state machine is implemented by toggling a single class (s-idle, s-email, s-password, s-peek, s-success, s-error) on #app and letting targeted CSS rules do the animation via display toggles and cubic-bezier transforms.
💡
Metaphor
The state machine here is like a mood ring for the whole page: change one class on the root element and the entire visual tone shifts — expressions appear, arms jump, pupils dilate — all because the CSS file is a giant 'if the ring is red, be angry; if it is blue, be calm' rulebook. You never have to touch the SVG from JavaScript at all.
Key concepts
CSS state machine SVG character animation pupil cursor tracking with viewBox math display-based expression swapping cubic-bezier transforms for arms keyframe animations (bounce, shake) form UX feedback
