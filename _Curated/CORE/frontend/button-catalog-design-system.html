Catálogo de Botões Padrão
A Portuguese-language standalone HTML/CSS demo page cataloging a button design system with primary, file, navigation, secondary, tertiary, and icon-only button variants.
The fourth time you catch yourself copy-pasting a MudButton with the same color and icon, you know it's time. Left to evolve organically, a codebase grows 37 slightly-different Save buttons - nine blue, twelve green, a rogue purple, and one that someone made orange for a demo and never fixed. This page is the antidote: one file that says 'this is the Save button, here is what it looks like, copy this markup.'
Executive summary
This is a self-contained HTML page that renders a visual catalog of reusable button styles organized into categories: Primary (Add/Save/Edit/Delete/Clone), File Actions (Download/Export PDF/Import), Navigation (Back/Refresh/Sync/Login), Secondary (Details/Cancel/Complete/Reopen), Tertiary (List/Close/Expand/Collapse), and System (icon-only buttons with CSS tooltips for Menu/Settings/Show/Hide/User). It uses Font Awesome icons, CSS variables for theming, and defines hover animations. The page contains almost no prose - it's effectively a live style guide for copy-pasting button markup. There is no JavaScript despite being in the JScript folder.
💡
Metaphor
This is the swatch book a painter carries to every job. Before you start mixing colors on site, you flip to the page with all the standard shades - 'wall primary', 'trim secondary', 'danger red' - and point at what you want. Doing it this way guarantees every room in every house painted by your crew looks like it belongs to the same company, and no junior painter has to guess whether red means 'delete' or 'accent'.
