Exemplo Cores - CSS Color System Example
A self-contained HTML/CSS demo showing a full web color system using CSS custom properties (primary, secondary, neutrals, feedback colors) with hover states and feedback boxes.
Your designer hands you a Figma file with nineteen shades of red and says 'the primary button should use red #3 but if it's in a warning box use red #5 with 10% transparency.' You can hard-code those hex values across 47 files and pray nothing drifts - or you can define them once as CSS variables and never touch a hex again.
Executive summary
A single-file HTML demo that establishes a reusable CSS design token system via :root custom properties. It defines primary (red #df2e26), secondary (orange #f26d28), neutrals, feedback colors (success green, error red, warning orange, info blue), links, and spacing variables - then applies them to a complete page layout (header, sidebar, main grid, footer) with buttons, feedback boxes, and links demonstrating hover states. Useful as a visual reference for a brand color system implemented purely with CSS variables.
💡
Metaphor
This file is like a paint chip booklet from a hardware store, except it's also showing you how the paint looks on a fake wall. All the colors are declared in one place at the top (the :root section), given names like --color-primary and --success, and then referenced everywhere else with var(). Change the hex in one place and the entire page repaints - like swapping out the master tin and every wall in the house updating simultaneously.
