Why do neural networks sometimes refuse to learn even when the error is huge? The answer isn't a bad algorithm — it's that the neurons you most want to change are the ones least able to change. And a single multiplication, output * (1 - output), is what prevents your training run from wasting its time on them.
Executive summary
This mini-page focuses on one crucial concept from neural network training: the sigmoid derivative. It explains that the sigmoid function squashes any input into 0-1, but the real magic is the derivative = output * (1 - output) — a number between 0 and 0.25 that tells backpropagation 'how sensitive this neuron currently is'. When output is 0.5 the derivative is 0.25 (peak learning); when output is 0.9 or 0.1 the derivative is 0.09 (the neuron is near saturation and barely moves). It shows an example of predicting 'Dog' at 0.9 when the truth is 0.0: with the derivative the scaled error is -0.081 instead of -0.9, which prevents wasted updates and helps the network learn smoother decision boundaries.

Metaphor
The sigmoid derivative is like trying to steer a car that's already glued to the kerb. If you're in the middle of the lane (output 0.5), even a small nudge on the wheel changes where the car goes — that's maximum learning. If you've already slammed against the left kerb (output 0.05) or the right kerb (output 0.95), turning the wheel harder won't help — the car is physically stuck. The derivative multiplier is the network saying 'I know you want me to move, but I literally can't right now — don't bother spending energy here.'

Why Sigmoid Derivative Matters

The sigmoid function squashes any input into a value between 0 and 1. But here's the key insight:

The slope (derivative) tells us how "sensitive" the neuron is to changes.

When we backpropagate errors, we multiply by this derivative. Why? Because it answers: "If I nudge the input a little, how much does the output actually change?"

Sigmoid Function

Output = 1 / (1 + e-x)

Sigmoid Derivative

Derivative = output × (1 - output)

The Math in Plain English

error_to_backpropagate = raw_error × output × (1 - output)

Example: The network predicted 0.9 for "Dog" but expected 0.0 (wrong animal).

Scenario Output Raw Error Derivative Scaled Error Learning
Without derivative 0.9 -0.9 — -0.900 Big change 💥
With derivative 0.9 -0.9 0.9 × 0.1 = 0.09 -0.081 Small change 🎯

Why is the small change better?

When output is 0.9, the neuron is in the "flat" part of the sigmoid curve. Even a large weight change barely moves the output! The derivative tells us: "Don't waste effort here — this neuron can barely change anyway."

This is why networks can get "stuck" — if neurons saturate, gradients vanish and learning stalls.
The derivative prevents wasting updates on neurons that can't change much anyway.

Why This Improves Generalization

Without the derivative, the network learns "all or nothing" — it pushes neurons hard toward 0 or 1.

With the derivative, learning is proportional to sensitivity. The network develops more nuanced internal representations.

Result: When you input "maybe" (1) instead of "yes" (2), the network handles the ambiguity better because it learned smoother decision boundaries, not sharp cliffs.
