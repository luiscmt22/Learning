The Three Levels of Training
Training flows through three levels, like a company hierarchy. Each level has ONE job and doesn't worry about the details of other levels.
LEVEL 1
BetterGame.TrainInitialNetwork()
"The CEO" — Decides WHEN and HOW LONG to train
void TrainInitialNetwork ()
{
for (int i = 0; error > expectedError; i++) // Keep going until good enough
{
foreach (var animal in animals) // For each training example
{
network. Train (animal.features, expected, lr); // Delegate to Level 2
}
}
}
What this level knows: All animals, the target error, when to stop
What it DOESN'T know: How networks work internally, what weights are

🎯 The Key Insight: Each level only talks to the level directly below it.
BetterGame never touches a Neuron directly. Neurons don't know BetterGame exists.
This separation makes the code manageable!

The Zigzag Problem: Each animal pulls the weights in its own direction.
Training is like a tug-of-war where we keep switching who's pulling!

Stochastic: Update → Update → Update → Update (zigzag!)
Batch: Accumulate → Accumulate → Accumulate → Average & Update ONCE (smooth!)

Inside the Neuron: Method by Method
Let's zoom in on exactly what happens inside a single neuron.
METHOD 1
Train() — Immediate Update
public void Train (double[] inputs, double learningRate, double error)
{
// For each weight...
for (int i = 0; i // Immediately change the weight!
Weights[i] += learningRate * error * inputs[i];
// ↑ how fast ↑ how wrong ↑ how relevant
}
Bias += learningRate * error;
}
Example:
Weight[2] = 0.50
→
0.50 + (0.1 × 0.06 × 2) = 0.512
→
Weight[2] = 0.512 ✓
METHOD 2
AccumulateGradients() — Store for Later
public void AccumulateGradients (double[] inputs, double error)
{
// For each weight...
for (int i = 0; i // DON'T change the weight! Store the gradient instead.
_weightGradients[i] += error * inputs[i];
// ↑ Note: no learningRate here!
}
_biasGradient += error;
_accumulatedCount++; // Remember we saw one more example
}
Example:
_weightGradients[2] = 0.0
→
0.0 + (0.06 × 2) = 0.12
→
Stored! (not applied)
Why no learningRate?
We're just collecting "votes" right now. The learningRate is applied later when we actually update, so we can adjust how big a step to take.
METHOD 3
ApplyGradients() — Average & Update
public void ApplyGradients (double learningRate)
{
if (_accumulatedCount == 0) return ; // Nothing to apply
for (int i = 0; i // NOW we update, using the AVERAGE gradient
Weights[i] += learningRate * (_weightGradients[i] / _accumulatedCount);
// ↑ sum of votes ↑ number of voters
_weightGradients[i] = 0; // Reset for next batch
}
Bias += learningRate * (_biasGradient / _accumulatedCount);
_biasGradient = 0;
_accumulatedCount = 0;
}
After 3 animals:
_weightGradients[2] = 0.21
→
Average = 0.21 / 3 = 0.07
Apply:
Weight[2] = 0.50
→
0.50 + (0.1 × 0.07) = 0.507
→
Weight[2] = 0.507 ✓
