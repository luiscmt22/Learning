Visão Geral do Sistema

Objetivo

O Sistema de Produção de Chão de Fábrica é um sistema de execução de manufatura (MES) em tempo real, projetado para rastrear ordens de produção, consumo de materiais e movimentos de inventário num ambiente de produção.

Funcionalidades Principais

Gestão de ordens de produção em tempo real

Rastreamento de consumo de materiais com análise de variância

Geração automática de movimentos de stock

Análise de padrões históricos de consumo

Suporte para produção multi-máquina

Integração com sistema ERP Primavera

Stack Tecnológica

Frontend: Blazor Server (.NET 8)

Framework UI: MudBlazor

Backend: ASP.NET Core

Base de Dados: Entity Framework Core

Integração Externa: Primavera ERP

MaterialConsumptionDto

public class MaterialConsumptionDto

{

public int GastosFaseId { get; set; }

public int? ArtigoId { get; set; }

public string ArtigoNome { get; set; }

public string ArtigoCodigo { get; set; }

public string Unidade { get; set; }

// Quantidades

public decimal PlannedQuantity { get; set; }

public decimal ActualQuantity { get; set; }

public decimal Stock { get; set; }

// Análise de Variância

public decimal Variance => ActualQuantity - PlannedQuantity;

public decimal VariancePercentage =>

PlannedQuantity != 0 ? (Variance / PlannedQuantity) * 100 : 0;

// Dados Históricos

public decimal? HistoricalAverage { get; set; }

public decimal? TotalConsumed { get; set; }

public int? ProductionCount { get; set; }

}
