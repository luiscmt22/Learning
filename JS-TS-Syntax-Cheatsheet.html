JS / TS Syntax Cheatsheet

Braces, commas, colons and dots, for a C# developer reading React + TypeScript. The examples come from Driveway (and the course author's code). Start with section 1: most lines that look scary are just objects nested inside objects.

1Reading a scary line: the routine

  1. Find the outermost bracket pair. ( ) = arguments or parameters. [ ] = an array (or a by-position pattern). { } = it depends on where it is; see section 2.
  2. Commas only split items at the current level. A comma inside an inner { } belongs to that inner object, not to the outer one.
  3. Read each item on its own. It's one of: key: value, ...spread, or a shorthand name.

Bracket colours by depth:  level 0level 1level 2level 3

Example A: building an object as the only argument (author's AuctionForm)

const newAuction = await createListing(        // ( = argument list. It has ONE argument:
    {                                           // { in a value position = build an object
        ...data,                                // item 1: copy every property of data
        reservePrice: data.reservePrice || 0,   // item 2: overwrite reservePrice ("" becomes 0)
        // item 3: overwrite auctionEnd (local time from the input → UTC string)
        auctionEnd: new Date(data.auctionEnd).toISOString()
    }
);

Result: the same object as data, with two properties replaced. In C# this is a record with expression: data with { ReservePrice = ..., AuctionEnd = ... }.

Example B: an object whose values are objects (features/session/actions.ts)

// left of = : a PATTERN (take accessToken out).   right of = : a call with ONE object argument
const {accessToken} = await auth.api.getAccessToken({
    body: {useAccountCookie: true},       // item 1: key "body", value = ANOTHER object
    headers: await headers()               // item 2: key "headers", value = the awaited result
});

Example C: a nested pattern (AuctionForm with React Hook Form)

const {control, handleSubmit, setFocus, formState: {isSubmitting}} = useForm();
//      item 1   item 2        item 3    item 4: go INSIDE formState and take isSubmitting
// Variables created: control, handleSubmit, setFocus, isSubmitting. NOT formState.

Example D: JSX props holding an object holding objects (AuctionForm)

// 1st { = "JS goes here".   2nd { = an object literal.
rules={{
    required: "Auction end date/time is required",   // item 1
    validate: value =>                               // item 2: the value is a function (lambda)
        new Date(value) > new Date() || "Auction end date must be in the future"
}}

3Commas

A comma separates items in a list. Lists appear in: object literals, arrays, arguments, parameters, patterns, imports, generic parameters. In a type shape you may use , or ;.

ListExample
Object literal{ method: "POST", body: json, headers: h }
Array["openid", "profile", "auctionApp"]
Argumentsnew URL("/", request.url)
Parameters(key: "seller" | "winner", value: string) => ...
Pattern (object)const {pageNumber, pageSize, searchTerm} = params
Pattern (array, by position)const [isPending, startTransition] = useTransition()
Importsimport {useEffect, useTransition} from "react"
A comma never ends a statement. That's ; (or a new line). If you see a comma, you're inside a list: find which bracket opened it.
Trailing commas are allowed: {a, b,}, [1, 2,], import {useEffect,}. They're harmless, and they make diffs cleaner when you add an item later.

In a pattern, the colon is never followed by a type. It's followed by a new name (rename) or another pattern (go inside). To type a pattern, put the type after the whole pattern:
const {accessToken: token}: {accessToken: string} = result;

With spread, later wins. {...data, reservePrice: 0} → 0 wins. {reservePrice: 0, ...data} → data's value wins. So put the overrides after the spread.

Traps you've already hit:
String(undefined) || "/" → "undefined" (a non-empty string is truthy).

An await pauses only the function it's written in. An async arrow handed to something else (startTransition, setTimeout, .forEach) is not awaited by the outer function. It's like C#'s _ = Task.Run(async () => ...).
